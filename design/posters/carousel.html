The design decision

Data only. Old builds never break.

No code is shipped at runtime. Each build says which protocol it reads, and the server never sends a payload it can't render.

Published versions

v4 protocol 2
v3 protocol 1
v2 protocol 1
v1 protocol 1
This week's build · Freshed-Protocol: 2
Gets v4
The newest version it can read.
Two-year-old build · Freshed-Protocol: 1
Gets the newest protocol 1 version
Unknown components fall back. It never crashes.
